# 주문 — 눈 단면 평면 2D 그림 (eye-diagram.svg 새로 그리기)

인체 시뮬레이터 **신경계 · 눈의 실시간 조절** 장면에 쓰는 그림입니다.
지금 파일을 **그 자리에 그대로 갈아 끼웁니다.**

---

## 0. 왜 다시 그리는가 — 이 그림만 옛 스타일입니다

도식 열넷을 재는 검사 쪽(`_check.html`)에서 **유일하게 걸린 그림**입니다.

| 잰 것 | 지금 | 다른 열세 장 | 한계 |
|---|---|---|---|
| `radialGradient` | **5개** | 0개 | 0개 |
| `filter` (발광) | **3개** | 0개 | 0개 |
| 그라데이션 밝기 차 | **60.6%** | 0~7.5% | 15% |
| `linearGradient` | 11개 | 0~5개 | 조각당 1개 |

그래서 이 그림만 **네온이 켜진 SF 도면**처럼 보입니다 — 각막이 형광 하늘색으로
빛나고, 수정체 한가운데가 발광하고, 황반에 흐림 효과가 걸려 있습니다.
바탕에도 어두운 방사형 그라데이션이 깔려 있어 **다른 배경 위에 얹을 수 없습니다.**

**해부학은 손댈 것이 없습니다.** 각막-공막, 홍채-각막, 진대-수정체, 진대-섬모체,
시각신경-망막, 황반-망막 여섯 이음매를 재 보니 **전부 틈 0**입니다.
**이 붙어 있는 관계를 그대로 지켜 주세요.** 바꿀 것은 겉모습뿐입니다.

---

## 1. 규격

- `viewBox="0 0 1000 700"` — 그대로. 좌표를 바꾸면 이름표가 다 어긋납니다.
- **배경을 깔지 마세요.** 지금 `spaceBg` 가 화면 전체를 덮고 있는데 없앱니다.
  투명한 채로 두면 엔진이 제 바탕 위에 얹습니다.
- **`<text>` 0개.** 이름표는 엔진이 HTML 로 얹습니다.
- **`radialGradient` · `filter` · `feGaussianBlur` · 발광 · 순백 하이라이트 금지.**
- `linearGradient` 는 써도 되지만 **조각 하나에 하나, stop 두 개,
  같은 색조, 밝기 차 15% 안쪽**. 순백(`#ffffff`) 금지.
  납작한 두 번째 색으로 그늘을 한 겹 까는 쪽이 더 또렷합니다.

## 3. 조각 이름 (id) — 하나도 빠지면 안 됩니다

```
scleraLayer    공막 (흰자)
choroidLayer   맥락막
retina         망막
vitreous       유리체
cornea         각막
iris           홍채
pupil          동공        ← 엔진이 크기를 바꾼다
lens           수정체      ← 엔진이 두께를 바꾼다
zonule         진대        ← 엔진이 길이를 바꾼다
ciliaryBody    섬모체      ← 엔진이 크기를 바꾼다
fovea          황반
opticNerve     시각 신경
```

뒤의 넷(`pupil`·`lens`·`zonule`·`ciliaryBody`)은 엔진이 실시간으로
크기를 바꿉니다. **한 조각으로 그려 주세요.** 여러 조각으로 나누면
한쪽만 커집니다.

## 5. 하지 말아야 할 것

- 배경 사각형·방사형 무늬 (지금 있는 `spaceBg` 를 없앱니다)
- 발광, 흐림, 순백 하이라이트, 네온 테두리
- 영어 글자
- 바깥눈근육 같은 곁가지 — 이 장면은 **원근 조절과 명암 조절**만 다룹니다.
  지금 왼쪽 위·아래에 떠 있는 붉은 조각 둘은 빼 주세요.

## 6. 받고 나서 제가 재는 것

- 위 열두 개 `id` 가 다 있는가
- `<text>` 0개, `radialGradient` 0개, `filter` 0개
- `linearGradient` 가 있다면 stop 둘, 밝기 차 **15% 안**, 순백 없음
- 화면 전체를 덮는 조각이 없는가 (배경 없음)
- 여섯 이음매가 그대로 **틈 0** 인가
  (각막↔공막, 홍채↔각막, 진대↔수정체, 진대↔섬모체, 시각신경↔망막, 황반↔망막)
- `pupil` · `lens` · `zonule` · `ciliaryBody` 가 각각 조각 하나인가
- 눈금(0~1000, 0~700) 밖으로 나간 조각이 없는가
