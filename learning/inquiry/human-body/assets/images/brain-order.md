# 주문 — 뇌 정중 단면 평면 2D 그림 (brain-diagram.svg)

인체 시뮬레이터 **신경계 · 1. 뇌의 구조** 장면에 쓸 그림입니다.

---

## 0. 왜 다시 그리는가

지금은 `nervous-brain.webp` 라는 **회색 사진**이 깔려 있습니다.

- 어두운 배경 위에 **어두운 회색 뇌**라 대비가 낮아 잘 안 보입니다.
- 대뇌·소뇌·뇌줄기가 **다 같은 회색**이라 어디가 어디인지 색으로 갈리지 않습니다.
  시험은 부위를 갈라 묻는데, 그림이 갈라 주지 않습니다.
- 부위를 고르면 **형광 보라 원**이 뇌의 한 조각을 덮습니다. SF 화면 같습니다.
- 그림 비율이 화면과 달라 위아래에 검은 띠가 생깁니다.

같은 방의 다른 장면(눈·반사·귀)은 이미 **단색 평면 2D 도식**으로 바꿨습니다.
이 장면만 사진입니다.

## 1. 규격

- `viewBox="0 0 1000 700"`
- 배경을 깔지 마세요. 투명하게 둡니다.
- **`<text>` 0개.** 이름표는 엔진이 HTML 로 얹습니다.
- **`radialGradient` · `filter` · 발광 · 순백 하이라이트 금지.**
- `linearGradient` 는 조각 하나에 하나, stop 두 개, 같은 색조, **밝기 차 15% 안**.
- 조각마다 `id`.

## 2. 무엇을 그리나

**뇌를 한가운데에서 자른 옆모습(정중 단면)** 입니다. 얼굴은 **왼쪽**을 봅니다.
교과서에서 가장 흔한 그림이고, 여섯 부위가 한 장에 다 나오는 유일한 각도입니다.

## 3. 조각 이름 (id) — 여섯 부위는 서로 다른 색

```
cerebrum       대뇌   — 주름진 큰 덩어리. 위쪽 대부분을 차지한다.
diencephalon   간뇌   — 대뇌 속 한가운데. 시상과 시상하부.
midbrain       중간뇌 — 간뇌 아래 짧은 토막
pons           다리뇌 — 중간뇌 아래 볼록한 부분 (이름표는 안 붙지만 뇌줄기 모양에 필요)
medulla        연수   — 다리뇌 아래, 척수로 이어지는 부분
cerebellum     소뇌   — 뒤쪽 아래. 나뭇가지 같은 속결이 보이게
spinalCord     척수   — 연수에서 아래로 내려가는 굵은 줄기
corpusCallosum 뇌들보 — 대뇌 좌우를 잇는 활 모양 (있으면 정중 단면임이 드러남)
```

**대뇌·간뇌·중간뇌·소뇌·연수·척수 여섯은 반드시 서로 다른 색**이어야 합니다.
학생이 색만 보고도 갈라야 합니다.

## 6. 받고 나서 제가 재는 것

- 위 여덟 개 `id` 가 다 있는가
- `<text>` 0개, `radialGradient` · `filter` 0개, 밝기 차 15% 안
- 여섯 부위의 칠 색이 **서로 다른가** (같은 색이 둘 있으면 되돌립니다)
- 이어져야 할 곳이 닿아 있는가 (틈 0):
  간뇌↔중간뇌, 중간뇌↔다리뇌, 다리뇌↔연수, 연수↔척수, 소뇌↔다리뇌,
  대뇌↔간뇌, 뇌들보↔대뇌
- 위에서 아래로의 차례가 맞는가 (대뇌 → 간뇌 → 중간뇌 → 다리뇌 → 연수 → 척수)
- 눈금(0~1000, 0~700) 밖으로 나간 조각이 없는가
