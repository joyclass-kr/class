# 주문 — 뇌 정중 단면 평면 2D 그림 (brain-diagram.svg)

인체 시뮬레이터 **신경계 · 1. 뇌의 구조** 장면에 쓸 그림입니다.

---

## 0. 왜 다시 그리는가

지금은 `nervous-brain.webp` 라는 **회색 사진**이 깔려 있습니다.

- 어두운 배경 위에 **어두운 회색 뇌**라 대비가 낮아 잘 안 보입니다.
- 대뇌·소뇌·뇌줄기가 **다 같은 회색**이라 어디가 어디인지 색으로 갈리지 않습니다.
  시험은 부위를 갈라 묻는데, 그림이 갈라 주지 않습니다.
- 부위를 고르면 **형광 보라 원**이 뇌의 한 조각을 덮습니다. SF 화면 같습니다.
- 그림 비율이 화면과 달라 위아래에 검은 띠가 생깁니다.

같은 방의 다른 장면(눈·반사·귀)은 이미 **단색 평면 2D 도식**으로 바꿨습니다.
이 장면만 사진입니다.

## 1. 규격

- `viewBox="0 0 1000 700"`
- 배경을 깔지 마세요. 투명하게 둡니다.
- **`<text>` 0개.** 이름표는 엔진이 HTML 로 얹습니다.
- **그늘은 넣어 주세요.** 어떻게 넣는지는 아래 「그늘」 칸에 적었습니다.
- 조각마다 `id`.

## 2. 무엇을 그리나

**뇌를 한가운데에서 자른 옆모습(정중 단면)** 입니다. 얼굴은 **왼쪽**을 봅니다.
교과서에서 가장 흔한 그림이고, 여섯 부위가 한 장에 다 나오는 유일한 각도입니다.

## 3. 조각 이름 (id) — 여섯 부위는 서로 다른 색

```
cerebrum       대뇌   — 주름진 큰 덩어리. 위쪽 대부분을 차지한다.
diencephalon   간뇌   — 대뇌 속 한가운데. 시상과 시상하부.
midbrain       중간뇌 — 간뇌 아래 짧은 토막
pons           다리뇌 — 중간뇌 아래 볼록한 부분 (이름표는 안 붙지만 뇌줄기 모양에 필요)
medulla        연수   — 다리뇌 아래, 척수로 이어지는 부분
cerebellum     소뇌   — 뒤쪽 아래. 나뭇가지 같은 속결이 보이게
spinalCord     척수   — 연수에서 아래로 내려가는 굵은 줄기
corpusCallosum 뇌들보 — 대뇌 좌우를 잇는 활 모양 (있으면 정중 단면임이 드러남)
pituitary      뇌하수체 — 간뇌 아래에 콩알처럼 매달린 것
```

**뇌하수체를 꼭 넣어 주세요.** 제가 처음 주문에서 빠뜨렸습니다.
항상성 단원에서 「간뇌가 명령하고 뇌하수체가 호르몬을 내보낸다」로
나오는데, 그림에 없으면 어디 붙은 것인지 가르칠 수가 없습니다.

**대뇌·간뇌·중간뇌·소뇌·연수·척수 여섯은 반드시 서로 다른 색**이어야 합니다.
학생이 색만 보고도 갈라야 합니다.

## 그늘 — 덩어리져 보이게 (이건 꼭 넣어 주세요)

납작한 단색만으로는 색종이 오려 붙인 것처럼 보입니다.
기관마다 **같은 색이 어두워지는 그늘**을 한 겹 넣어 덩어리져 보이게 해 주세요.

- `linearGradient` 를 조각마다 하나, **stop 두 개, 같은 색조, 밝기 차 10~25%**.
  (보기: 아래 색표의 「칠」에서 「테두리」 쪽으로. 밝기 차 15%, 색조 차 2도쯤입니다.)
- 빛은 **왼쪽 위**에서 옵니다. 오른쪽 아래가 어둡습니다. 온 그림에서 같게 해 주세요.
- 가장자리 안쪽에 **어두운 선을 한 줄** 더 그으면 두께가 생깁니다.
- 결(주름·갈래·근육결)은 **가는 선**으로 그어 주세요. 색을 따로 채우지 마세요.

막는 것은 이 넷뿐입니다. 나머지는 마음껏 해 주세요.

| 막는 것 | 왜 |
|---|---|
| `radialGradient` · `filter` · 발광 | 빛나 보여서 SF 화면이 됩니다 |
| 순백(`#ffffff`)·순흑 stop | 전구나 구멍처럼 보입니다 |
| 밝기 차 28% 넘김 | 한 덩어리가 두 조각으로 보입니다 |
| 색조 차 25도 넘김 | 딴 색으로 넘어가 딴 기관처럼 보입니다 |

## 5. 하지 말아야 할 것

- 사진 합성·실사 렌더, 반짝이는 반사광
- 배경 사각형, 형광 원
- 영어 글자
- **혈관은 넣지 마세요.** 중학교 시험에 안 나오는데 부위 경계를 가립니다.
  뇌줄기에서 나가는 신경 뿌리는 아주 옅은 선으로 두어도 좋습니다.

## 6. 받고 나서 제가 재는 것

- 위 아홉 개 `id` 가 다 있는가
- `<text>` 0개, `radialGradient` · `filter` 0개
- 그늘 밝기 차 28% 안, 색조 차 25도 안, 순백·순흑 stop 없음
- **그늘이 없는 조각이 몇인가** (전부 납작하면 색종이처럼 보입니다)
- 여섯 부위의 칠 색이 **서로 다른가** (같은 색이 둘 있으면 되돌립니다)
- 이어져야 할 곳이 닿아 있는가 (틈 0):
  간뇌↔중간뇌, 중간뇌↔다리뇌, 다리뇌↔연수, 연수↔척수, 소뇌↔다리뇌,
  대뇌↔간뇌, 뇌들보↔대뇌, 뇌하수체↔간뇌
- 위에서 아래로의 차례가 맞는가 (대뇌 → 간뇌 → 중간뇌 → 다리뇌 → 연수 → 척수)
- 눈금(0~1000, 0~700) 밖으로 나간 조각이 없는가
