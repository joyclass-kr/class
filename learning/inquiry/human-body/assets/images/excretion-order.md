# 주문 — 전신 배설계 평면 2D 그림 (excretion-diagram.svg)

인체 시뮬레이터 **배설계 · 1. 전신 배설계 (콩팥·오줌관·방광)** 장면에 쓸 그림입니다.

---

## 0. 왜 다시 그리는가

지금은 `excretion-hero-v2.webp` 라는 **어두운 남색 X선 사진**이 깔려 있습니다.

- 몸이 **화면 오른쪽에만 치우쳐** 있고 왼쪽 절반이 텅 빈 남색입니다.
  거기에 **빛나는 청록 알갱이 띠**가 흘러갑니다. SF 화면입니다.
- 몸이 파랗게 비치는 X선 느낌이라 **콩팥 속이 안 보입니다.**
  겉질·속질·콩팥깔때기는 시험에 나오는데 그림이 갈라 주지 않습니다.
- 오른쪽에 붙은 **네프론 돋보기 원이 너무 작아** 안이 무엇인지 알 수 없습니다.

## 1. 규격

- `viewBox="0 0 700 900"` — 세로로 긴 아랫배입니다.
- 배경을 깔지 마세요. 투명하게 둡니다.
- **`<text>` 0개.** 이름표는 엔진이 HTML 로 얹습니다.
- **그늘은 넣어 주세요.** 어떻게 넣는지는 아래 「그늘」 칸에 적었습니다.
- 조각마다 `id`.

## 2. 무엇을 그리나

**허리에서 아랫배까지를 앞에서 본 도식**입니다. 몸통은 **화면 한가운데**에.

콩팥 두 개 → 오줌관 두 개 → 방광 하나 → 요도 하나로
**오줌이 내려가는 길이 한 줄로 이어져** 보여야 합니다.

**오른쪽 콩팥 하나는 반으로 잘라** 속을 보여 주세요. 겉질·속질·콩팥깔때기가
색으로 갈려야 합니다. (앞에서 본 그림이므로 **화면 왼쪽이 몸의 오른쪽**입니다.)

**네프론 돋보기**는 화면 오른쪽 아래에 **큰 원**으로 따로 그립니다.
지금처럼 손톱만 하면 안 됩니다. 원 지름을 **220 넘게** 잡아 주세요.

## 그늘 — 덩어리져 보이게 (이건 꼭 넣어 주세요)

납작한 단색만으로는 색종이 오려 붙인 것처럼 보입니다.
기관마다 **같은 색이 어두워지는 그늘**을 한 겹 넣어 덩어리져 보이게 해 주세요.

- `linearGradient` 를 조각마다 하나, **stop 두 개, 같은 색조, 밝기 차 10~25%**.
  (보기: 아래 색표의 「칠」에서 「테두리」 쪽으로. 밝기 차 15%, 색조 차 2도쯤입니다.)
- 빛은 **왼쪽 위**에서 옵니다. 오른쪽 아래가 어둡습니다. 온 그림에서 같게 해 주세요.
- 가장자리 안쪽에 **어두운 선을 한 줄** 더 그으면 두께가 생깁니다.
- 결(주름·갈래·근육결)은 **가는 선**으로 그어 주세요. 색을 따로 채우지 마세요.

막는 것은 이 넷뿐입니다. 나머지는 마음껏 해 주세요.

| 막는 것 | 왜 |
|---|---|
| `radialGradient` · `filter` · 발광 | 빛나 보여서 SF 화면이 됩니다 |
| 순백(`#ffffff`)·순흑 stop | 전구나 구멍처럼 보입니다 |
| 밝기 차 28% 넘김 | 한 덩어리가 두 조각으로 보입니다 |
| 색조 차 25도 넘김 | 딴 색으로 넘어가 딴 기관처럼 보입니다 |

## 5. 하지 말아야 할 것

- 배경 사각형, 빛나는 알갱이 띠, X선처럼 비치는 파란 몸
- 사진 합성·실사 렌더
- 영어 글자
- 소화관·허파 (이 장면은 배설만 다룹니다)
- **부신은 넣지 마세요.** 콩팥 위에 얹혀 있지만 배설과 상관없고,
  잘라 놓은 콩팥의 겉질과 헷갈립니다.

## 6. 받고 나서 제가 재는 것

- 위 스물두 개 `id` 가 다 있는가
- `<text>` 0개, `radialGradient` · `filter` 0개
- 그늘 밝기 차 28% 안, 색조 차 25도 안, 순백·순흑 stop 없음
- **그늘이 없는 조각이 몇인가** (전부 납작하면 색종이처럼 보입니다)
- 오줌 길이 끊기지 않는가 (틈 0):
  오른쪽 콩팥↔오른쪽 오줌관, 왼쪽 콩팥↔왼쪽 오줌관,
  오줌관 둘↔방광, 방광↔요도
- 콩팥동맥↔대동맥, 콩팥정맥↔대정맥이 닿아 있는가
- **겉질·속질·콩팥깔때기의 칠 색이 서로 다른가**
- 속질이 겉질 **안에** 있고, 콩팥깔때기가 속질 **안쪽**에 있는가
- **네프론 돋보기 원의 지름이 220 넘는가**
- 사구체가 보먼주머니 안에 있는가
- **기관마다 그늘이 들어 있는가** (`linearGradient` 가 없는 조각이 몇인가)
- 몸통이 가운데 있는가 (좌우 여백 차이 40 안쪽)
- 눈금(0~700, 0~900) 밖으로 나간 조각이 없는가
