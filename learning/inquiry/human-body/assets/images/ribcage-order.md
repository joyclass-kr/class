# 주문 — 갈비뼈·가로막 평면 2D 그림 (ribcage.svg)

인체 시뮬레이터 **호흡계 · 3. 갈비뼈·가로막과 부피·압력** 장면의 왼쪽
「몸속에서 일어나는 일」 자리에 쓸 그림입니다.

지금은 엔진이 대충 그린 것이 들어가 있습니다 — **갈비뼈가 허공에 뜬 흰 곡선
몇 줄이고, 폐가 그냥 타원 두 개**입니다. 등뼈도 복장뼈도 없어서 갈비뼈가
어디에 붙어 있는지 알 수 없습니다.

들숨·날숨으로 움직이는 것은 엔진이 합니다. **완전히 숨을 내쉰 자세 한 벌**만
그려 주시면 됩니다.

---

## 0. 이 그림이 왜 필요한가 — 모형과 달라야 합니다

이 장면은 화면을 둘로 나눠 **왼쪽에 몸속, 오른쪽에 종 모형(고무막 실험)** 을
놓고 「고무막 = 가로막, 풍선 = 폐, 유리종 = 흉강」을 가르칩니다.

그런데 지금은 **둘이 똑같이 생겼습니다.** 양쪽 다 붉은 타원 두 개라서
어느 쪽이 몸이고 어느 쪽이 기구인지 알 수 없습니다. 그러면 이 장면이
가르치려는 것이 통째로 사라집니다.

오른쪽 모형은 이미 **실험 기구처럼** 다시 그렸습니다 — 유리종에 반사선,
고무마개, 목을 묶은 분홍 고무 풍선, 잡아당기는 꼭지.

**그러니 왼쪽은 확실하게 「사람 몸속」으로 보여야 합니다.**

| | 오른쪽 (모형) | 왼쪽 (몸속) — 이번 주문 |
|---|---|---|
| 담는 것 | 매끈한 유리종 | **갈비뼈 우리** (등뼈·복장뼈에 붙은 활) |
| 공기주머니 | 고무 풍선 (매끈한 물방울 모양) | **갈래로 나뉜 폐** (왼쪽 2, 오른쪽 3) |
| 아래 막 | 고무 시트 (굵은 선 하나) | **근육 가로막** (두께가 있는 돔) |
| 색 | 분홍 고무 · 맑은 유리 | 진한 붉은 살빛 · 뼈 흰색 |


## 1. 규격

- `viewBox="0 0 500 560"` — 이 눈금 그대로. (전체 화면의 왼쪽 칸입니다.)
- 바탕 없음. 배경 `<rect>` 를 깔지 마세요.
- **`<text>` 를 하나도 넣지 마세요.** 이름표는 엔진이 HTML 로 얹습니다.
  그림 안 글씨는 창이 커지면 같이 커져서 옆 글씨와 크기가 어긋납니다.
- 그라데이션은 **`linearGradient` 만, 조각 하나에 하나, stop 두 개,
  같은 색조, 밝기 차 15% 안쪽**. 순백(`#ffffff`) 금지.
  `radialGradient` · `filter` · 발광 **금지**.
- 조각마다 `id` 를 붙여 주세요.

## 3. 조각 이름 (id)

```
spine        등뼈 — 뒤쪽 한가운데 세로로. 갈비뼈가 여기서 나온다.
sternum      복장뼈 — 앞쪽 한가운데 세로로. 갈비뼈가 여기에 붙는다.

<g id="ribs">          ← 갈비뼈 묶음. 엔진이 통째로 들었다 놨다 한다.
   rib1 ... rib7       갈비뼈 일곱 쌍. 좌우가 한 조각이어도 좋다.
</g>

<g id="lungs">         ← 폐 묶음. 엔진이 부풀렸다 줄였다 한다.
   lungLeft  왼쪽 폐 — 두 갈래(위·아래엽)
   lungRight 오른쪽 폐 — 세 갈래(위·가운데·아래엽)
</g>

trachea      기관 — 목에서 내려오는 관
bronchusL    왼쪽 기관지
bronchusR    오른쪽 기관지
diaphragm    가로막 — 위로 볼록한 돔 하나 (완전히 내쉰 자세)
```

**왼쪽 폐는 두 갈래, 오른쪽 폐는 세 갈래입니다.** 심장이 왼쪽에 자리를
차지하므로 왼쪽 폐가 더 작습니다. 시험에 나옵니다.

## 4. 갈비뼈를 그릴 때 꼭 지킬 것

지금 그림의 가장 큰 흠은 **갈비뼈가 아무 데도 안 붙어 있는 것**입니다.

- 갈비뼈는 **뒤쪽 등뼈에서 나와 앞쪽 복장뼈로 이어지는 활 모양**입니다.
  양쪽 끝이 등뼈와 복장뼈에 **닿아 있어야** 합니다.
- 위쪽 갈비뼈는 짧고 덜 기울고, 아래로 갈수록 길고 많이 기웁니다.
- 갈비뼈 사이가 고르게 벌어져 있어야 합니다.
- 굵기는 3~5 정도로 가늘게. 뼈처럼 보이되 굵은 막대가 되지 않게.

## 6. 하지 말아야 할 것

- 배경 사각형, 격자, 방사형 무늬
- 발광, 순백 하이라이트, 원통처럼 보이는 명암
- 영어 글자
- 심장·간 같은 다른 기관 (이 장면은 숨쉬기만 다룹니다)

## 7. 받고 나서 제가 재는 것

- 위 열두 개 `id` 가 다 있는가
- `<text>` 0개, `radialGradient` · `filter` 0개
- `linearGradient` 가 있다면 stop 둘, 밝기 차 15% 안, 순백 없음
- **갈비뼈 양 끝이 등뼈와 복장뼈에서 6 안쪽에 닿아 있는가** (일곱 쌍 전부)
- 갈비뼈 사이 간격이 고른가 (가장 넓은 곳 ÷ 가장 좁은 곳 ≤ 1.6)
- 오른쪽 폐가 세 갈래, 왼쪽 폐가 두 갈래로 나뉘어 있는가
- 왼쪽 폐가 오른쪽 폐보다 작은가
- 눈금(0~500, 0~560) 밖으로 나간 조각이 없는가
