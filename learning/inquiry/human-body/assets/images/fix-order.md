# 주문 — 받은 그림 넉 장 손보기

넉 장 가운데 **셋은 이미 화면에 걸었습니다.** 잘 되었습니다.
자율신경 한 장만 다시 그려야 하고, 나머지 셋은 손볼 곳이 하나씩 있습니다.

---

## 0. 먼저 — 그라데이션 이름을 파일마다 다르게

이번에 진짜 흠이 하나 나왔습니다.

도식마다 `gradCerebrum`, `gradMedulla`, `gradLiver` 같은 **흔한 이름**을 쓰셨는데,
저희는 한 쪽(page)에 도식을 **여러 장 겹쳐 얹습니다.**
신경계 방은 뇌 도식과 반사 중추 도식을 같이 얹는데, 이름이 겹치니
**대뇌가 남의 그라데이션을 가져다 써서 통째로 빈 것처럼 보였습니다.**

열아홉 장을 훑어 보니 겹치는 이름이 **열 개**였습니다.

```
gradArtery     ← nephron-diagram, villus-diagram
gradVein       ← nephron-diagram, villus-diagram
gradPancreas   ← glucose-diagram, digestive-tract
gradLiver      ← glucose-diagram, digestive-tract
gradCerebrum   ← reflex-centers, brain-diagram      ← 실제로 터졌습니다
gradMidbrain   ← reflex-centers, brain-diagram
gradMedulla    ← reflex-centers, brain-diagram, excretion-diagram
gradSpinalCord ← reflex-centers, brain-diagram
gradCallosum   ← reflex-centers, brain-diagram
gradBladder    ← autonomic-diagram, excretion-diagram
```

엔진에서 얹을 때 이름을 갈아 끼우도록 고쳐 두었으니 **지금 것은 급하지 않습니다.**
다만 **앞으로는 파일 이름을 앞에 붙여** 주세요 — `brainCerebrum`, `excBladder` 처럼.

**조각 이름(`cerebrum`, `bladder` 같은 것)은 그대로 두세요.** 엔진이 그 이름으로 찾습니다.
바꿔야 하는 것은 `<defs>` 안의 그라데이션 이름뿐입니다.

## 1. 자율신경 (autonomic-diagram.svg) — 다시 그려 주세요

이 한 장만 못 걸었습니다.

**무엇이 문제인가:** 몸 윤곽은 큰데 **속이 텅 비었습니다.**
눈·기관지·심장·소화관·방광·부신이 몸 한가운데 **좁은 세로 통로**에
손톱만 하게 몰려 있어서, 무엇이 무엇인지 알 수 없습니다.
교감(주황)·부교감(초록) 줄기도 너무 가늘어 거의 안 보입니다.

**이렇게 고쳐 주세요.**

- 기관을 **크게** 그려 주세요. 심장은 **최소 90×90**, 허파는 **최소 130×110**,
  소화관은 **최소 140×120**, 방광은 **최소 70×70**, 눈은 **최소 60×40**.
  (눈금은 1000×700 입니다. 지금은 다들 40 안팎입니다.)
- 기관을 세로 한 줄에 쌓지 마세요. **몸통 너비를 넉넉히 써서** 벌려 놓아 주세요.
  머리(눈) → 가슴(허파·심장) → 배(소화관·부신) → 아랫배(방광) 로 내려가되,
  좌우로도 자리를 나눠 서로 닿지 않게 해 주세요.
- 두 신경 줄기는 **굵기 5 이상**. 가지도 **굵기 3.5 이상**.
- 몸 윤곽은 더 **옅게** (지금은 윤곽만 눈에 띕니다).

**같은 기관에 두 신경이 함께 붙어 반대로 조절한다**는 것이 이 장면의 전부입니다.
기관이 안 보이면 가르칠 것이 없습니다.

## 3. 배설계 (excretion-diagram.svg) — 돋보기 속을 채워 주세요

콩팥 단면과 오줌 길은 아주 좋습니다.

- **네프론 돋보기 원(지름 250)이 거의 비어 있습니다.** 원만 키우고 속을 안 채웠습니다.
  원 넓이의 **2/3 이상**을 쓰도록 크게 그려 주세요.
  - `glomerulus` 사구체 — 실뭉치처럼 **여러 번 감긴** 모양 (지금은 점 하나)
  - `bowman` 보먼주머니 — 사구체를 **감싸는 컵**
  - `tubule` 세뇨관 — **구불구불** 길게
  - `collecting` 집합관 — 아래로 내려가는 굵은 관
  - `peritubular` 세뇨관을 **감고 있는** 모세혈관
- 대동맥·대정맥이 **십자 모양으로 굵게** 가로지릅니다. 콩팥동맥·콩팥정맥은
  대혈관에서 **갈라져 나오는 가지**처럼 비스듬히 그려 주세요.

## 5. 제가 재는 것

- 그라데이션 이름이 파일마다 다른가
- 자율신경: 기관 여섯의 크기가 위에 적은 값 이상인가, 서로 닿지 않는가,
  두 줄기 굵기가 5 이상인가

  소뇌 넓이가 대뇌의 1/4 아래인가, 눈금 밖 조각 0
- 배설계: 돋보기 속 다섯 조각이 원 넓이의 2/3 이상을 쓰는가
- 소화관: 간문맥 굵기, 항문이 가운데(x 330~370)인가
- 늘 재던 것 — `<text>` 0, `radialGradient`·`filter` 0, 그늘 밝기 차 28% 안,
  색조 차 25도 안, 순백·순흑 없음, 이음매 틈 0, `id` 안 사라짐
