# 주문 — 팔 뼈대 평면 2D 그림 (arm-skeleton.svg)

인체 시뮬레이터 **골격계 · 관절과 길항근** 장면에 쓸 뼈 그림입니다.
지금은 제가 대충 그린 뼈가 들어가 있습니다. 그 자리만 갈아 끼웁니다.

**근육(이두근·삼두근)은 그리지 마세요.** 근육은 각도에 따라 두께와 길이가
계속 바뀌어야 해서 엔진이 매 판 다시 그립니다. 이 주문은 **뼈만**입니다.

---

## 1. 규격

- `viewBox="0 0 1000 700"` — 이 눈금 그대로.
- 바탕 없음. 배경 `<rect>` 를 깔지 마세요. 투명하게 둡니다.
- **`<text>` 를 하나도 넣지 마세요.** 이름표는 엔진이 HTML로 얹습니다.
  그림 안에 글자가 있으면 글씨 크기가 제각각이 되고 휴대폰에서 깨집니다.
- **그라데이션은 범위를 제한합니다.** 아주 없애라는 뜻이 아닙니다.
  전에 있던 그림이 형광등 봉처럼 보인 까닭은 뼈 폭 하나에
  `#334155 → #ffffff → #475569`, 곧 **밝기 차 73%에 순백 반사까지** 넣었기
  때문입니다. 아래 안에서는 써도 좋습니다.
  - `linearGradient` 만, 조각 하나에 **하나**, **stop 두 개**
  - 두 색은 **같은 색조**, **밝기 차 15% 안쪽** (예: `#e2e8f0` ↔ `#c3ccd8`)
  - **순백(`#ffffff`) 금지**, 하이라이트 점·띠 금지
  - `radialGradient` · `filter` · `feGaussianBlur` · `drop-shadow` · 발광 **금지**
  - 그라데이션 대신 **납작한 두 번째 색으로 그늘을 한 겹 깔아도 좋습니다.**
    작은 화면에서는 이쪽이 더 또렷합니다.
- 조각마다 `id` 를 붙여 주세요. 아래 이름 그대로 씁니다.
- 선: `stroke-width="2.5"`, `stroke-linejoin="round"`.

## 2. 자세와 자리

**팔을 완전히 편 자세**(위팔과 아래팔이 일직선, 아래를 향함)로 그려 주세요.
굽힌 그림은 필요 없습니다. 아래팔은 엔진이 팔꿈치를 축으로 돌립니다.

| 자리 | 좌표 |
|---|---|
| 어깨 관절 한가운데 | (470, 120) |
| 팔꿈치 관절 한가운데 | (470, 370) |
| 손목 한가운데 | (470, 620) |

- **앞쪽(이두근이 붙는 쪽, 노뼈 쪽)은 오른쪽(+x)** 입니다.
- **뒤쪽(삼두근이 붙는 쪽, 자뼈·팔꿈치머리)은 왼쪽(−x)** 입니다.

## 3. 조각 이름 (id)

```
scapula    어깨뼈 — 위팔뼈가 걸리는 자리만. 크지 않게.
humerus    위팔뼈 — 위 끝은 둥근 관절머리, 아래 끝은 도르래 모양.
                   한 덩어리 path 하나로.

<g id="forearm">        ← 이 묶음 하나만 엔진이 돌립니다. 꼭 묶어 주세요.
   ulna    자뼈  — 뒤쪽(왼쪽). 위 끝의 팔꿈치머리가 뒤로 튀어나오게.
   radius  노뼈  — 앞쪽(오른쪽). 위 끝은 원판 모양 노뼈머리,
                   위쪽 1/4 안쪽에 노뼈거친면이 살짝 튀어나오게.
   hand    손뼈  — 손목뼈·손허리뼈·손가락을 간단히. 자세히 그리지 마세요.
</g>
```

노뼈와 자뼈는 **사이가 벌어져 두 가닥으로 또렷하게 보여야 합니다.**
시험에 「이두근은 노뼈에, 삼두근은 자뼈(팔꿈치머리)에 붙는다」가 나옵니다.

## 4. 보이지 않는 표시 (엔진이 좌표를 읽는 자리)

`fill="none" stroke="none"` 인 `<circle r="1">` 다섯 개를 넣어 주세요.
화면에는 안 보이고, 엔진이 근육을 붙일 자리를 여기서 읽습니다.

```
pivotElbow               팔꿈치 회전축 = (470, 370)
attachBicepsOrigin       어깨뼈에서 이두근이 시작하는 자리
attachBicepsInsertion    노뼈거친면 (이두근 힘줄이 붙는 자리)
attachTricepsOrigin      어깨뼈에서 삼두근이 시작하는 자리
attachTricepsInsertion   팔꿈치머리 (삼두근 힘줄이 붙는 자리)
```

`attachBicepsInsertion` 과 `attachTricepsInsertion` 은 **`forearm` 묶음 안에**
넣어 주세요. 아래팔과 같이 돌아야 합니다.

| 무엇 | 칠 | 테두리 |
|---|---|---|
| humerus · radius · ulna | `#e2e8f0` | `#94a3b8` |

## 6. 모양은 자세히 — 이게 시험에 듣습니다

밋밋한 막대 두 개면 안 됩니다. **이름이 나오는 돌기는 알아볼 수 있게**
그려 주세요. 그래야 「이두근은 노뼈에, 삼두근은 자뼈에 붙는다」가
글이 아니라 그림으로 설명됩니다.

꼭 알아볼 수 있어야 하는 것:

| 자리 | 왜 |
|---|---|
| 위팔뼈 위 끝의 **둥근 관절머리** | 어깨 관절이 절구관절임을 보여 줌 |
| 위팔뼈 아래 끝의 **도르래** | 팔꿈치가 경첩관절이라 한 방향으로만 굽음 |
| 자뼈 위 끝의 **팔꿈치머리** (뒤로 튀어나옴) | 삼두근이 붙는 자리 |
| 노뼈 위 끝의 **원판 모양 노뼈머리** | 아래팔이 돌아가는 축 |
| 노뼈 위쪽 안쪽의 **노뼈거친면** | 이두근 힘줄이 붙는 자리 |
| 두 뼈 아래 끝의 **붓돌기** | 손목이 어디까지인지 |

## 7. 하지 말아야 할 것

- 원통처럼 보이는 명암, 순백 하이라이트, 네온 테두리, 발광
- 배경의 방사형 눈금·격자·부채꼴
- 영어 글자 (BICEPS, Humerus 같은 것)
- 뼈 속 결·구멍·해면뼈 무늬 — 돌기는 살리되 표면 무늬는 넣지 마세요

## 8. 받고 나서 제가 재는 것

- 위 여덟 개 `id` 가 다 있는가
- `<text>` 0개, `radialGradient`·`filter` 0개
- `linearGradient` 가 있다면 stop 이 둘뿐이고 두 색의 밝기 차가 15% 안쪽인가,
  `#ffffff` 가 안 쓰였는가
- `forearm` 묶음 안에 ulna·radius·hand 와 붙는 자리 두 개가 들어 있는가
- `pivotElbow` 가 (470, 370) 에서 2 안쪽인가
- 0°부터 150°까지 돌려 보며 팔꿈치가 어긋나지 않는가
