# 정보·컴퓨터 한영 표준 용어집

이 문서는 `정보·컴퓨터` 과정의 메뉴, 설명, 문제, 피드백, 이미지 대체 텍스트에서 사용하는 한국어와 영어 표기를 통일한다. 학습 화면에서는 **한국어를 기본 표현**, 영어를 보조 표현으로 사용한다.

## 1. 화면 표기 원칙

### 기본 형식

- 메뉴·카드: `운영체제` / `(Operating System)`
- 약어가 중요한 용어: `중앙 처리 장치` / `(Central Processing Unit, CPU)`
- 본문 첫 등장: `운영체제(Operating System, OS)`
- 같은 화면의 반복 등장: `운영체제` 또는 `OS`
- 문제 선택지: 학습 목표가 영어 용어 확인이 아니라면 한국어를 먼저 쓴다.
- 제품명은 번역하지 않는다: `Windows`, `Android`, `iOS`, `iPadOS`, `macOS`, `ChromeOS`, `Linux`

### 대소문자와 단위

- 약어: `CPU`, `GPU`, `RAM`, `SSD`, `HDD`, `USB`, `URL`, `DNS`, `RGB`
- 운영체제 제품명: `Windows`, `Android`, `iOS`, `iPadOS`, `macOS`, `ChromeOS`, `Linux`
- `bit`의 기호는 소문자 `b`, `Byte`의 기호는 대문자 `B`로 구별한다.
- 파일 크기: `KB`, `MB`, `GB`, `TB`
- 전송 속도: `kbps`, `Mbps`, `Gbps`
- 초당 바이트: `KB/s`, `MB/s`, `GB/s`
- 픽셀: `px`, 화면 밀도: `ppi`, 주사율: `Hz`, 프레임률: `fps`

### 어린이 화면에서 피할 표현

- `메모리`만 단독으로 쓰지 않는다. `RAM(작업 메모리)` 또는 `저장 공간`으로 구별한다.
- `바로가기`만으로 키보드 단축키를 뜻하지 않는다. `키보드 단축키`라고 쓴다.
- `즐겨찾기`와 `북마크`를 무조건 다른 기능으로 설명하지 않는다. 브라우저에 따른 이름 차이도 함께 설명한다.
- `화면 크기`, `해상도`, `화질`을 같은 뜻으로 쓰지 않는다.
- `Wi-Fi`와 `인터넷`을 같은 뜻으로 쓰지 않는다.
- `Chrome`과 `Google 검색`을 같은 뜻으로 쓰지 않는다.
- `파일 삭제`, `아이콘 제거`, `앱 제거`를 같은 동작으로 쓰지 않는다.

## 2. 컴퓨터와 시스템

| 한국어 표준 표현 | 영어 표준 표현 | 수업용 의미 |
|---|---|---|
| 정보·컴퓨터 | Information & Computing | 메뉴와 교과 영역 이름 |
| 컴퓨터 | Computer | 명령에 따라 데이터를 처리하는 기기 |
| 디지털 기기 | Digital Device | 컴퓨터, 태블릿, 스마트폰 등 디지털 데이터를 다루는 기기 |
| 아날로그 | Analog | 값이 끊기지 않고 연속적으로 변하는 방식이나 표현 |
| 디지털 | Digital | 정보를 구분되는 값이나 숫자로 나타내고 처리하는 방식 |
| 아날로그 신호 | Analog Signal | 시간에 따라 연속적으로 변하는 신호 |
| 디지털 신호 | Digital Signal | 구분되는 단계의 값으로 표현되는 신호 |
| 연속적인 값 | Continuous Value | 두 값 사이에도 더 많은 값이 이어지는 표현 |
| 이산적인 값 | Discrete Value | 정해진 단계나 구분된 값으로 나타내는 표현 |
| 아날로그-디지털 변환 | Analog-to-Digital Conversion, ADC | 아날로그 신호를 측정해 디지털 데이터로 바꾸는 과정 |
| 디지털-아날로그 변환 | Digital-to-Analog Conversion, DAC | 디지털 데이터를 스피커 출력 등의 아날로그 신호로 바꾸는 과정 |
| 컴퓨터 시스템 | Computer System | 하드웨어와 소프트웨어가 함께 작동하는 전체 |
| 데이터 | Data | 컴퓨터가 저장하고 처리하는 정보의 표현 |
| 정보 | Information | 데이터를 해석해 얻은 의미 |
| 명령 | Instruction / Command | 컴퓨터에게 수행할 일을 나타내는 지시 |
| 입력 | Input | 컴퓨터 안으로 데이터나 명령을 넣는 것 |
| 처리 | Processing | 명령에 따라 계산하고 판단하는 것 |
| 저장 | Storage / Saving | 데이터를 나중에도 사용할 수 있게 보관하는 것 |
| 출력 | Output | 처리 결과를 화면, 소리, 인쇄물 등으로 내보내는 것 |
| 하드웨어 | Hardware | 만질 수 있는 컴퓨터 장치와 부품 |
| 소프트웨어 | Software | 컴퓨터에서 실행되는 명령과 프로그램 |
| 프로그램 | Program | 특정 작업을 수행하도록 만든 명령의 모음 |
| 앱 | App / Application | 사용자가 목적에 따라 실행하는 응용 프로그램 |
| 시스템 소프트웨어 | System Software | 운영체제처럼 컴퓨터의 기본 작동을 관리하는 소프트웨어 |
| 응용 소프트웨어 | Application Software | 문서, 그림, 웹 탐색 등 사용자 작업을 수행하는 소프트웨어 |
| 펌웨어 | Firmware | 장치 안에 저장되어 기본 동작을 제어하는 소프트웨어 |

## 3. 하드웨어와 부품

| 한국어 표준 표현 | 영어 표준 표현 | 수업용 의미 |
|---|---|---|
| 본체 | Computer Case / System Unit | 주요 내부 부품이 들어 있는 부분 |
| 주변 장치 | Peripheral Device | 컴퓨터에 연결해 사용하는 입력·출력·저장 장치 |
| 입력 장치 | Input Device | 키보드, 마우스처럼 입력을 보내는 장치 |
| 출력 장치 | Output Device | 모니터, 스피커처럼 결과를 보여 주는 장치 |
| 입출력 장치 | Input/Output Device, I/O Device | 입력과 출력을 모두 수행하는 장치 |
| 중앙 처리 장치 | Central Processing Unit, CPU | 명령을 해석하고 계산하며 작업을 처리하는 장치 |
| 프로세서 | Processor | CPU를 가리키거나 데이터를 처리하는 장치를 넓게 이르는 말 |
| 시스템 온 칩 | System on a Chip, SoC | CPU·GPU·메모리 제어·통신 기능 등을 하나의 칩에 통합한 장치. 스마트폰과 태블릿에서 흔히 사용 |
| 모바일 프로세서 | Mobile Processor | 배터리 사용 시간과 발열을 고려해 모바일 기기용으로 구성한 프로세서 또는 SoC |
| CPU 코어 | CPU Core | CPU 안에서 명령을 처리하는 독립적인 작업 단위 |
| 스레드 | Thread | CPU가 처리하는 명령 작업의 흐름 |
| 클록 속도 | Clock Speed | CPU가 일정 시간 동안 동작하는 기본 속도, 보통 GHz로 표시 |
| 그래픽 처리 장치 | Graphics Processing Unit, GPU | 많은 그래픽·행렬 계산을 동시에 처리하는 장치 |
| 그래픽 카드 | Graphics Card | GPU, 그래픽 메모리, 냉각 장치 등을 포함한 확장 장치 |
| 비디오 메모리 | Video Random Access Memory, VRAM | GPU가 화면과 그래픽 데이터를 잠시 저장하는 전용 메모리 |
| 주기억장치·RAM | Random Access Memory, RAM | 현재 사용하는 앱과 데이터를 잠시 올려두는 빠른 작업 공간 |
| 캐시 메모리 | Cache Memory | CPU 가까이에서 자주 쓰는 데이터를 매우 빠르게 보관하는 작은 메모리 |
| 저장 장치 | Storage Device | 전원을 꺼도 파일과 프로그램을 보관하는 장치 |
| 솔리드 스테이트 드라이브 | Solid-State Drive, SSD | 반도체 메모리에 데이터를 저장하는 빠른 저장 장치 |
| 하드 디스크 드라이브 | Hard Disk Drive, HDD | 회전하는 자기 디스크에 데이터를 저장하는 장치 |
| 플래시 메모리 | Flash Memory | 전원을 꺼도 데이터가 남는 반도체 저장 메모리 |
| 모바일 플래시 저장 장치 | Mobile Flash Storage | 스마트폰·태블릿에서 앱과 파일을 보관하는 반도체 저장 장치. PC의 SSD와 역할은 비슷하지만 형태와 연결 방식이 다름 |
| 메인보드 | Motherboard / Mainboard | CPU, RAM, 저장 장치 등 부품을 연결하는 주 회로 기판 |
| 로직 보드·주기판 | Logic Board / Main Board | 스마트폰·태블릿에서 SoC, RAM, 저장 장치, 통신 칩 등이 붙는 중심 회로 기판 |
| 회로 기판 | Circuit Board | 전자 부품과 연결 회로가 놓인 판 |
| 슬롯 | Slot | RAM이나 확장 카드를 끼우는 연결 자리 |
| 소켓 | Socket | CPU 등 특정 부품을 장착하는 연결 자리 |
| 데이터 버스 | Data Bus | 부품 사이에서 데이터를 전달하는 통로 |
| 전원 공급 장치 | Power Supply Unit, PSU | 필요한 전력을 각 부품에 공급하는 장치 |
| 배터리 | Battery | 전기를 저장해 이동 중에도 기기를 작동시키는 장치 |
| 전원 관리 칩 | Power Management Integrated Circuit, PMIC | 배터리 전력을 부품별로 알맞게 나누고 충전을 관리하는 칩 |
| 방열판 | Heat Sink | 부품의 열을 넓게 퍼뜨리는 금속 부품 |
| 냉각팬 | Cooling Fan | 공기를 움직여 부품의 열을 식히는 장치 |
| 포트 | Port | 케이블이나 장치를 연결하는 접속구 |
| 커넥터 | Connector | 케이블 끝이나 장치가 맞물리는 연결 부분 |
| USB | Universal Serial Bus, USB | 전원과 데이터를 전달하는 공통 연결 규격 |
| USB-A | USB Type-A | 넓은 직사각형 모양의 USB 커넥터 |
| USB-C | USB Type-C | 위아래 구분 없이 연결 가능한 작은 USB 커넥터 |
| HDMI | High-Definition Multimedia Interface, HDMI | 디지털 영상과 소리를 전달하는 연결 규격 |
| 오디오 단자 | Audio Jack | 이어폰, 헤드폰, 마이크 등을 연결하는 단자 |
| 네트워크 어댑터 | Network Adapter | 유선 또는 무선 네트워크 연결을 담당하는 장치 |
| 셀룰러 모뎀 | Cellular Modem | 이동통신망과 데이터를 주고받도록 신호를 처리하는 장치 |
| 안테나 | Antenna | Wi-Fi·Bluetooth·이동통신·GPS 등의 전파를 보내고 받는 부품 |
| 카메라 모듈 | Camera Module | 렌즈와 이미지 센서 등을 묶어 사진과 영상을 입력하는 부품 |
| 진동 모터·햅틱 장치 | Vibration Motor / Haptic Actuator | 진동이나 촉각 반응으로 상태와 입력 결과를 알려 주는 출력 장치 |
| 모니터 | Monitor | 컴퓨터의 시각 정보를 보여 주는 외부 출력 장치 |
| 디스플레이 | Display | 화면을 보여 주는 장치나 표시 영역의 일반 명칭 |
| 터치스크린 | Touchscreen | 화면 표시와 터치 입력을 함께 수행하는 장치 |
| 키보드 | Keyboard | 글자, 숫자, 명령을 입력하는 장치 |
| 마우스 | Mouse | 포인터를 움직이고 화면의 대상을 선택하는 장치 |
| 트랙패드 | Trackpad / Touchpad | 손가락 움직임으로 포인터를 조작하는 평평한 입력 장치 |
| 웹캠 | Webcam | 컴퓨터에 연결하거나 내장된 영상 입력 장치 |
| 마이크 | Microphone | 소리를 입력하는 장치 |
| 스피커 | Speaker | 소리를 출력하는 장치 |
| 프린터 | Printer | 화면의 문서나 그림을 종이에 출력하는 장치 |

## 5. 운영체제와 화면 구성

| 한국어 표준 표현 | 영어 표준 표현 | 적용 환경·주의 |
|---|---|---|
| 운영체제 | Operating System, OS | 하드웨어, 앱, 파일, 사용자를 관리하는 기본 소프트웨어 |
| 부팅 | Boot / Booting | 전원을 켜고 운영체제가 사용할 준비를 하는 과정 |
| 종료 | Shut Down | 운영체제와 기기를 안전하게 끄는 동작 |
| 다시 시작 | Restart | 종료한 뒤 자동으로 다시 켜는 동작 |
| 절전 | Sleep | 작업 상태를 유지하면서 전력 사용을 줄이는 상태 |
| 잠금 화면 | Lock Screen | 계정에 다시 들어가기 전 잠금 상태의 화면 |
| 로그인 | Sign In / Log In | 계정의 사용자임을 확인하고 들어가는 것 |
| 로그아웃 | Sign Out / Log Out | 현재 계정의 사용을 마치는 것 |
| 바탕화면 | Desktop | Windows·macOS 등에서 작업의 바탕이 되는 화면 |
| 홈 화면 | Home Screen | Android·iOS·iPadOS에서 앱과 위젯을 배치하는 기본 화면 |
| 시작 메뉴 | Start Menu | Windows에서 앱, 검색, 전원 기능 등을 여는 메뉴 |
| 작업 표시줄 | Taskbar | Windows에서 앱과 시스템 상태를 보여 주는 막대 |
| Dock | Dock | macOS·iPadOS 등에서 자주 쓰는 앱을 표시하는 영역 |

## 9. 데이터·bit·byte·용량

| 한국어 표준 표현 | 영어 표준 표현 | 수업용 의미 |
|---|---|---|
| 이진수 | Binary Number | 0과 1만으로 나타내는 수 |
| 이진 표현 | Binary Representation | 두 상태를 이용해 데이터와 명령을 나타내는 방법 |
| 비트 | bit / Binary Digit | 0 또는 1의 두 상태를 나타내는 가장 작은 정보 단위 |
| 바이트 | Byte | 일반적으로 8개의 bit로 이루어진 데이터 단위 |
| 킬로바이트 | Kilobyte, KB | 약 1천 Byte 크기의 단위 |
| 메가바이트 | Megabyte, MB | 약 1백만 Byte 크기의 단위 |
| 기가바이트 | Gigabyte, GB | 약 10억 Byte 크기의 단위 |
| 테라바이트 | Terabyte, TB | 약 1조 Byte 크기의 단위 |
| 키비바이트 | Kibibyte, KiB | 정확히 1,024 Byte인 이진 단위. 심화에서만 사용 |
| 메비바이트 | Mebibyte, MiB | 정확히 1,024 KiB인 이진 단위. 심화에서만 사용 |
| 기비바이트 | Gibibyte, GiB | 정확히 1,024 MiB인 이진 단위. 심화에서만 사용 |
| 파일 크기 | File Size | 한 파일에 들어 있는 데이터의 양 |
| 저장 용량 | Storage Capacity | 저장 장치가 담을 수 있는 전체 데이터의 양 |
| 문자 인코딩 | Character Encoding | 글자와 숫자 코드를 Byte 데이터로 표현하는 약속 |
| 유니코드 | Unicode | 여러 언어의 문자에 공통 번호를 정한 국제 표준 |
| 무손실 압축 | Lossless Compression | 원본 데이터를 잃지 않고 크기를 줄이는 압축 |
| 손실 압축 | Lossy Compression | 사람이 덜 느끼는 일부 데이터를 줄여 크기를 크게 줄이는 압축 |
| 데이터 전송률 | Data Transfer Rate | 일정 시간 동안 전송되는 데이터의 양 |
| 대역폭 | Bandwidth | 통신 경로가 일정 시간에 전달할 수 있는 데이터 용량의 범위 |
| 초당 비트 | bits per second, bps | 통신 속도를 나타내는 기본 단위 |
| 초당 메가비트 | Megabits per second, Mbps | 인터넷 속도에 자주 사용하는 단위 |
| 초당 메가바이트 | Megabytes per second, MB/s | 파일 전송 속도에 사용하는 단위 |

### 단위 교육 주의

- 입문에서는 `KB → MB → GB → TB`의 크기 순서와 실제 사례를 먼저 익힌다.
- `1 KB = 1,024 B`라고 절대 규칙처럼 가르치지 않는다. 저장 장치 표기에는 1,000 기반 단위가 쓰이고, 일부 운영체제 표시는 1,024 기반 계산을 사용한다.
- 정확한 1,024 기반 단위는 심화 차시에서 `KiB`, `MiB`, `GiB`로 소개한다.
- 글자 하나의 Byte 수는 인코딩에 따라 달라지므로 `글자 한 자는 항상 1 Byte`라고 가르치지 않는다.

| 개인정보 | Personal Information / Personal Data | 개인을 알아보거나 연결할 수 있는 정보 |
| 민감정보 | Sensitive Information / Sensitive Data | 노출되면 큰 피해가 생길 수 있어 특별히 보호해야 하는 정보 |
| 위치 정보 | Location Data | 기기나 사람의 위치와 이동을 나타내는 데이터 |
| 디지털 발자국 | Digital Footprint | 온라인 활동 뒤에 남는 기록과 흔적 |
| 피싱 | Phishing | 믿을 만한 사람이나 기관인 척 정보를 빼내려는 속임수 |
| 악성 소프트웨어 | Malware / Malicious Software | 기기나 데이터를 해치거나 몰래 정보를 가져가는 소프트웨어 |
| 컴퓨터 바이러스 | Computer Virus | 다른 파일이나 프로그램에 퍼질 수 있는 악성 소프트웨어의 한 종류 |
| 스팸 | Spam | 원하지 않는데 반복적으로 오는 메시지나 광고성 정보 |
| 팝업 | Pop-Up | 현재 화면 위에 새로 나타나는 작은 창이나 패널 |
| 수상한 링크 | Suspicious Link | 목적지나 의도가 믿기 어려운 링크 |
| 출처 | Source | 정보나 파일을 제공한 사람, 기관, 사이트 |
| 게시자 | Publisher | 앱이나 소프트웨어를 배포한 주체 |
| 방화벽 | Firewall | 허용되지 않은 네트워크 통신을 막거나 관리하는 보안 기능 |
| 암호화 | Encryption | 허가받은 사람만 읽도록 데이터를 변환해 보호하는 방법 |
| 저작권 | Copyright | 창작물을 만든 사람이 가지는 법적 권리 |
| 출처 표시 | Attribution / Source Citation | 사용한 자료의 제작자와 출처를 밝히는 것 |
| 디지털 예절 | Netiquette / Digital Etiquette | 온라인에서 지켜야 할 존중과 소통 규칙 |
| 사이버 괴롭힘 | Cyberbullying | 디지털 공간에서 반복적으로 다른 사람을 괴롭히는 행동 |
| 차단 | Block | 특정 계정이나 연락의 접근을 막는 기능 |
| 신고 | Report | 위험하거나 규칙을 어긴 콘텐츠와 사용자를 서비스에 알리는 기능 |
| 디지털 웰빙 | Digital Wellbeing | 건강하고 균형 있게 디지털 기기를 사용하는 습관 |

## 15. 영문 병기 검수표

각 차시와 문제를 공개하기 전에 다음을 확인한다.

- [ ] 한국어와 영어가 실제로 같은 개념을 가리킨다.
- [ ] 약어의 전체 영어 명칭이 정확하다.
- [ ] 제품명 대소문자가 정확하다: `iOS`, `iPadOS`, `macOS`, `ChromeOS`.
- [ ] `bit(b)`와 `Byte(B)`의 대소문자가 정확하다.
- [ ] `shortcut`이 파일 바로가기인지 키보드 단축키인지 문맥에 표시되어 있다.
- [ ] `bookmark`와 `favorites`가 사용하는 브라우저와 함께 설명되어 있다.
- [ ] Windows의 `Taskbar`, ChromeOS의 `Shelf`, Apple의 `Dock`을 같은 이름으로 뭉뚱그리지 않았다.
- [ ] iOS·iPadOS의 `Control Center`와 Android·ChromeOS의 `Quick Settings`를 구별했다.
- [ ] `pointer`와 글 입력 위치인 `text cursor`를 구별했다.
- [ ] `memory`가 RAM인지 저장 공간인지 분명하다.
- [ ] `screen size`, `resolution`, `pixel density`, `scaling`을 구별했다.
- [ ] `browser`, `search engine`, `website`, `webpage`를 구별했다.
- [ ] `Wi-Fi`, `network`, `Internet`, `Web`을 구별했다.
- [ ] 다운로드·업로드의 방향은 학습자의 기기를 기준으로 설명했다.
- [ ] 파일 형식과 파일 확장자를 같은 뜻으로 단정하지 않았다.
- [ ] 운영체제 버전에 따라 달라지는 화면은 특정 버전의 유일한 정답처럼 제시하지 않았다.
