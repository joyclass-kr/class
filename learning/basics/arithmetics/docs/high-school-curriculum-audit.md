# 고등 연산 학습지 전수 감사

기준일: 2026-07-30
기준 교육과정: 교육부 고시 제2022-33호 `[별책 8] 수학과 교육과정`

## 감사 원칙

각 학습지는 제목이 아니라 실제 문제 생성 유형을 기준으로 판정한다.

- `충분`: 필수 계산 유형과 난도 상승이 구현됨
- `보강`: 단원은 있으나 중요한 계산 유형이 빠짐
- `누락`: 성취기준에 해당하는 학습지가 없음
- `중복`: 다른 학습지와 합쳐도 되는 쉬운 유형
- `재분류`: 내용은 유효하지만 현재 과목 배치가 잘못됨
- `범위 밖`: 교육과정에서 요구하지 않거나 지나치게 깊은 내용

교육과정의 큰 항목 하나를 그대로 학습지 하나로 보지 않는다. 성취기준, 성취기준 해설,
교과서에서 반복되는 계산 절차를 함께 확인하여 실제 연습 유형으로 세분화한다.

## 즉시 확인된 최우선 결함

1. 공통수학1 `항등식`이 독립 계산 유형으로 없다.
2. 나머지정리에 일차식·이차식 조건을 결합한 나머지 복원 유형이 없다.
3. 공통수학1의 근과 계수, 이차함수와 직선, 최대·최소, 연립이차방정식이 빠졌다.
4. 공통수학1 방정식 페이지가 유리·무리·절댓값·복이차 중심이라 공식 범위와 어긋난다.
5. 대수의 수학적 귀납법이 빠졌고 금융 수열은 공식 범위보다 과도하게 깊다.
6. 미적분Ⅰ 기본 미분에 미적분Ⅱ의 지수·로그·삼각함수 미분이 섞였다.
7. 미적분Ⅱ의 매개변수·음함수·역함수 미분과 이계도함수 활용이 약하다.
8. 기하의 공간도형 영역이 다른 영역보다 현저히 얕다.

## 다음 작업 순서

1. 55개 페이지별 실제 생성 유형과 문제 수를 확정한다.
2. 각 공식 성취기준에 연결되는 유형을 표에 표시한다.
3. `누락`을 먼저 추가하고 `범위 밖`을 보충/심화 구역으로 이동한다.
4. 같은 기초 동작만 반복하는 페이지는 통합한다.
5. 인수분해, 나머지정리, 방정식, 미분·적분처럼 숙련이 필요한 영역은 세분화한다.
