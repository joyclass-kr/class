# 고등 연산 학습지 전수 감사

기준일: 2026-07-30
기준 교육과정: 교육부 고시 제2022-33호 `[별책 8] 수학과 교육과정`

## 감사 원칙

각 학습지는 제목이 아니라 실제 문제 생성 유형을 기준으로 판정한다.

- `충분`: 필수 계산 유형과 난도 상승이 구현됨
- `보강`: 단원은 있으나 중요한 계산 유형이 빠짐
- `누락`: 성취기준에 해당하는 학습지가 없음
- `중복`: 다른 학습지와 합쳐도 되는 쉬운 유형
- `재분류`: 내용은 유효하지만 현재 과목 배치가 잘못됨
- `범위 밖`: 교육과정에서 요구하지 않거나 지나치게 깊은 내용

교육과정의 큰 항목 하나를 그대로 학습지 하나로 보지 않는다. 성취기준, 성취기준 해설,
교과서에서 반복되는 계산 절차를 함께 확인하여 실제 연습 유형으로 세분화한다.

### 독립 학습지와 통합 학습지의 기준

교육과정에 포함된 내용이라고 해서 모두 독립 학습지로 만들지 않는다.

다음 유형은 관련 상위 학습지 한 장에 통합한다.

- 공식이나 정의를 한 번 대입하면 끝나는 문제
- 단순한 값 읽기, 참·거짓 판정, 명칭 확인
- 숫자만 달라지고 풀이 동작이 완전히 같은 한 단계 문제
- 다음 계산 유형의 도입으로 1~2문제면 충분한 문제
- 별도로 반복해도 새로운 실수 교정이나 계산 자동화 효과가 적은 문제

통합 학습지는 한 장 안에서 다음 순서를 따른다.

1. 개념 확인 또는 가장 쉬운 계산 1~2문제
2. 괄호, 부호, 분수, 미지계수 등이 추가된 표준 계산
3. 두 개 이상의 개념을 연결하는 응용 계산
4. 조건을 거꾸로 사용하는 역산 또는 종합 계산

다음 유형은 독립 학습지로 유지하거나 더 세분화한다.

- 공식과 변형 절차를 즉시 꺼낼 수 있을 때까지 반복해야 하는 유형
- 부호, 차수, 정의역, 구간처럼 실수가 반복되는 유형
- 여러 단계의 계산 순서를 안정적으로 익혀야 하는 유형
- 이후 여러 단원의 공통 도구가 되는 유형
- 같은 단원 안에서도 풀이 알고리즘이 실질적으로 다른 유형

대표적으로 인수분해, 항등식과 미정계수법, 나머지정리, 방정식·부등식,
지수·로그 계산, 삼각함수 계산, 수열의 합, 미분법, 적분법은 집중 훈련 대상으로 본다.
