# 문제 점검 지침 — 전래동화 방으로

세계명작 예순 권 문제를 다 고치고 나서 정리한 것입니다.
전래동화도 같은 도구로 그대로 잴 수 있습니다.

---

## 1. 무엇이 문제인가

문제 447개를 만들어 놓고 **답이 본문과 맞는지만** 봤습니다.
오답이 쓸모 있는지는 아무도 안 봤어요. 그래서 이렇게 됐습니다.

```
세계명작 447문제 중 341개(76%)가 이야기를 안 보고도 풀렸습니다.
일곱 문제가 전부 새는 책이 열여섯 권이었습니다.
```

**전래동화도 재 봤습니다. 예순두 권 434문제 중 212개(49%)가 샙니다.**

```
⑤ 오답이 이야기에 아예 없는 말   181
② 책 제목에 답이 들어 있음        38
③ 윗문제에 나온 말이 정답         32
① 착한 말이 든 보기가 정답         2
④ 정답이 제일 긴 선지              1

많이 새는 책
  7/8  구렁덩덩 신선비      6/8  반쪽이        6/6  진주를 삼킨 거위
  6/12 흥부전               5/8  도깨비 감투   5/8  나무꾼과 호랑이 형님
  5/6  황소가 된 농부       5/6  좁쌀 한 톨    5/6  은혜 갚은 까치
```

선지 길이(④)는 전래동화 쪽이 이미 잘 맞춰져 있습니다.
손볼 곳은 **오답이 유령인 자리**와 **제목이 답을 알려 주는 자리**입니다.

---

## 2. 아이들이 쓰는 다섯 가지 수

| | 수 | 보기 |
|---|---|---|
| ① | 착한 것 고르기 | 진짜·착한·도와준·정직한 이 든 보기 |
| ② | 책 제목 베끼기 | 『진주를 삼킨 거위』 → 답은 「거위」 |
| ③ | 윗문제 베끼기 | 3번 물음에 나온 말이 6번 답 |
| ④ | 긴 선지 고르기 | 「요 스무 장과 이불 스무 장」 vs 「요 한 장」 |
| ⑤ | 특이한 선지 지우기 | 오답이 이야기에 아예 없어 그냥 지워짐 |

---

## 3. 고치는 기준은 하나입니다

> **오답도 이야기 안에 있던 것으로 만듭니다.**
> 읽은 아이만 "그건 다른 자리에서 나온 거잖아" 하고 지울 수 있어야 합니다.

```
✗ 왕비가 침대 맨 밑에 놓은 것은?
     완두콩 한 알 / 돌멩이 / 동전
     돌멩이도 동전도 이 이야기에 없습니다. 제목만 봐도 찍힙니다.

○ 왕비는 완두콩을 어디에 놓았나요?
     이불 맨 위 / 베개 속 / 나무 바닥 위
     셋 다 이야기에 나옵니다. 어디였는지는 읽어야 압니다.
```

```
○ 사냥꾼이 가방에서 꺼낸 것은?   가위 / 총 / 실
     총은 들었다 도로 내렸고, 실은 할머니가 배를 꿰맬 때 씁니다.
     셋 다 그 이야기 안의 물건입니다.

○ 큰언니는 왜 구두를 신지 못했나요?   발끝이 걸려서 / 뒤꿈치가 남아서 / 발가락이 아파서
     둘째가 뒤꿈치 때문이었습니다. 큰언니와 둘째를 구별해야 풀립니다.
```

**정답 자리도 흩습니다.** 늘 첫 자리면 그것도 수가 됩니다.
세계명작은 고친 뒤 첫 141 · 가운데 169 · 끝 137이 되었습니다.

## 4. 도구 쓰는 법

도구는 `world-tales/_check/bait.mjs` 한 개입니다.
`_books.json`만 있으면 어느 책 폴더든 그대로 잽니다. 옮겨 담을 것 없습니다.

```bash
node world-tales/_check/bait.mjs korea-tales           # 예순두 권 전부
node world-tales/_check/bait.mjs korea-tales banjjogi  # 한 권만
```

나오는 모양입니다.

```
■ 박혁거세 (bak-hyeokgeose)  4/6
  1. 여섯 촌장이 모여 의논한 것은 무엇인가요?
     → 임금을 모실 일   [⑤오답이유령]
     오답: 농사지을 땅 / 싸움을 벌일 일
```

`⑤오답이유령`은 오답 둘이 다 이야기에 없다는 뜻이고,
`⑤유령오답 1/2`는 둘 중 하나만 그렇다는 뜻입니다.

낱말은 조사를 떼고 뿌리 두 글자로 견줍니다(「빵을」→「빵」).
「것·수·때·말」처럼 뜻이 없는 매인말은 견주지 않습니다.

## 5. 예순 권 고치며 밟은 지뢰 다섯

**하나. 답을 고치다 이야기와 어긋나게 만들었습니다.**
「예복 없이 온 손님은?」의 답이 「잔치에서 쫓겨났다」였는데,
우리 본문에는 쫓겨나는 대목이 없습니다. 임금이 묻고 그 사람이
대답을 못 하는 데서 끝나요. 문제를 새로 낼 때마다 본문을 다시 봐야 합니다.

**둘. 숫자 문제는 오답도 이야기에 나온 수로 씁니다.**

```
✗ 요 스무 장과 이불 스무 장 / 이불 열 장 / 요 한 장   ← 제일 긴 것
○ 스무 장 / 마흔 장 / 한 장                            ← 셋 다 본문의 수
```

**셋. 제목이 답을 알려 주는 자리는 물음을 바꿉니다.**
『장화 신은 고양이』에서 답이 고양이나 장화면, 『알라딘과 요술 램프』에서
답이 램프면 표지만 보고 찍힙니다. 답을 다듬는 것보다 물음을 옮기는 편이 낫습니다.

```
✗ 막내가 물려받은 것은?        고양이 / 방앗간 / 당나귀
○ 막내가 고양이를 보고 놀란 까닭은?   말을 해서 / 장화를 신어서 / 자루를 메서
```

**넷. 오답을 고치다 또 새 겹침을 만듭니다.**
한 곳 고칠 때마다 그 책만 다시 돌려 보세요. 저는 그러다 세 번 되돌렸습니다.

**다섯. 말맛은 건드리지 않습니다.**
논리를 맞추려다 대사에서 재미를 깎아 낸 적이 있습니다.
「우리를 깔본 일은 반성하셔야 된답니다」 같은 깐깐한 한마디가 그 이야기의 맛입니다.

## 6. 차례

```
1. node bait.mjs <책폴더>          어디가 새는지 본다
2. 새는 문제만 골라 오답을 이야기 안의 것으로 바꾼다
3. 제목·윗문제가 걸리면 물음 자체를 옮긴다
4. 그 책만 다시 bait.mjs 로 확인
5. 답이 본문과 맞는지도 같이 본다 (world-tales는 _check/quiz.mjs 사용)
6. 정답 자리가 한쪽으로 쏠리지 않는지 마지막에 한 번
```

세계명작은 이 차례로 447문제를 **0개**까지 내렸습니다.
