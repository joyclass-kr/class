# 화성학 과정 검수 기록

## 검수 자료

- 812658295-백병동-화성학.pdf: 스캔본 목차와 대표 범위를 확인했다. 예비지식, 3화음과 전위, 7화음과 전위, 비화성음, 온음계·반음계 전조, 부속화음, 변화화음, 증6화음, 연속진행, 코랄과 종합문제를 포함한다.
- 음악이론 기본정리_240905.pdf: 큰보표·음자리표·조표, 음정의 도수와 성질, 음계와 조성, 로마숫자·기능화성, 3화음·7화음·sus·add·텐션·보이싱의 설명을 대조했다.
- 339222476-Elementary-Harmony-Part-I.pdf: 장·단음계와 음정, 주3화음 4성부, 제1전위, 경과음, 6/4화음, V7, 감·증3화음, 보조음과 앞꾸밈음까지 15개 장의 설명·풀이·연습 유형을 대조했다.
- 251536401-Traditional-Harmony.pdf: 159쪽의 16개 레슨에서 SATB 음역·중복·간격·밀집/개리, 네 성부진행 유형, 교차·중복·병행·숨은 완전음정, 주3화음과 전위, V7, 진행 원리, 세컨더리 도미넌트·이끎화음의 구조와 성부 해결을 대조했다.

자료의 장 순서나 문장을 복제하지 않았다. 현재 사이트에서 다음 개념을 정확히 이해하려면 반드시 필요한 선행 개념과, 서로 다른 수행 결과가 필요한 항목만 과정에 반영했다.

현재 과정의 목표는 전문 화성가 양성이 아니라 기초 훈련이다. 참고서의 청음·작성·오류 찾기 방식은 사용하지만, Part I의 모든 과제를 그대로 복제하지 않는다. 본격 전조와 고급 반음계 화성은 필수 진도에서 제외한다.

## 개념별 검수 원칙

현재 필수 과정은 9개 단원, 48개 학습 항목으로 구성한다. 차시마다 같은 설명 수·문제 수·도식 형식을 맞추지 않는다.

- 분류·순서·원인·해결 관계를 이해해야 할 때만 관계도를 사용한다.
- 계산 절차나 성부 작성처럼 중간 판단이 핵심일 때만 같이 풀기와 오개념 교정을 둔다.
- 음표 식별·단일 청음처럼 한 단계로 확인 가능한 내용은 짧은 설명과 직접 반복을 우선한다.
- 문제 수는 수행 목표를 충분히 반복할 만큼만 정하고, 정답은 문장 조건으로 하나가 되게 한다.
- 악보만 제시하고 설명을 대신하지 않는다. 개념에 적합한 표·관계도·악보·건반·소리 중 필요한 자료를 골라 사용한다.
- 건반형 활동은 정답 MIDI와 참고음이 표시 범위 안에 있는지 전체 항목을 검사하고 문제별 두 옥타브 범위를 자동 계산한다.
- 문제 문장에 조·음역·박·성부·적용 양식을 명시하고 취향이나 복수 해석이 가능한 표현을 금지한다.
- 목록에는 단원 아이콘과 차시 번호만 두고, 같은 장식 아이콘을 차시마다 반복하지 않는다.

## 악보 검수 기준

- 음표의 세로 위치는 음이름 철자 기준이며 MIDI 번호만으로 계산하지 않는다.
- C♯과 D♭처럼 같은 건반의 음도 서로 다른 보표 위치와 변화표로 표시한다.
- 가온도 C4에는 덧줄이 있고, 낮은음역과 높은음역을 함께 쓸 때 큰보표를 사용한다.
- 2도 간격의 음표머리는 좌우로 어긋나 겹치지 않는다.
- 화음은 동시에 수직 배치하고 음계·선율·성부선은 시간 순서로 수평 배치한다.
- 리드시트 예시는 멜로디 음 위에 해당 코드 기호를 같은 시간 위치로 표시한다.

## 청각자료 검수 기준

- 비교 청음은 가능한 한 같은 근음·음역·음량을 사용한다.
- 화음은 동시에, 음계와 선율은 시간 순서대로 재생한다.
- 모든 재생 음은 현재 9개 피아노 샘플의 피치 시프트 범위 안에 둔다.
- 샘플 로드 실패 시 합성음으로 재생하되 학습이 멈추지 않는다.
- 청음 정답은 음색·음량 같은 비본질적 단서가 아니라 실제 음정과 기능으로 결정된다.

## 문제 검수 기준

- 정답은 선택지에 정확히 한 번만 나타난다.
- 학습 예시 재생과 평가 문제를 구분하고, 바로 위 예시 버튼의 문구나 단순 재생 횟수를 그대로 고르는 문제를 내지 않는다.
- 모든 청음 문제에는 재생 데이터가 있고 모든 악보 문제에는 구현된 시각자료가 있다.
- 이명동음 철자가 답을 결정할 때 소리만으로 답하게 하지 않는다.
- 선행 항목은 현재 학습보다 앞에 있으며 순환 의존이 없다.
- 각 항목은 학습목표에 맞는 직접 활동과 충분한 확인 기회를 가진다.
- Part I 핵심 항목은 개념 복잡도에 따라 여러 설명·풀이·오류 교정·반복 문제를 선택적으로 사용한다.
