# 화성학 자체 가독성 점검

외부 교재의 편집 형식을 따라가지 않고, 이 과정 안에서 학생이 설명을 읽고 악보를 판독하고 소리로 확인한 뒤 직접 수행할 수 있는지를 기준으로 점검한다.

## 자체 점검 기준

- 현재 학습이 진도표나 소개 화면보다 먼저 보인다.
- 한 구간은 설명 → 악보·시각자료 → 청음 순서로 읽힌다.
- 본문은 17px, 최대 72ch 폭으로 제한하며 긴 문단을 피한다.
- 악보는 최대 960px까지 확보하고 좁은 화면에서는 비율을 유지한다.
- 모든 조작 대상은 44px 이상이며 터치와 트랙패드로 사용할 수 있다.
- 모든 설명 구간에는 시각자료와 서로 비교할 수 있는 청음 자료가 있다.
- 각 학습 항목은 설명만 읽고 끝나지 않고 구성·청음·진행 실습과 확인 문제로 마무리된다.
- 학습 항목 수와 문제 수는 고정하지 않고 내용과 선수 관계에 따라 정한다.

## 화면별 악보 표시 폭

| 화면 | 예상 악보 폭 |
| --- | ---: |
| 1024×768 | 약 879px |
| 1180×820 | 최대 960px |
| 768×1024 | 약 656px |

폭은 실제 CSS 컨테이너와 패딩을 기준으로 계산하며 계약 테스트로 고정한다. 768px 세로 화면에서도 가로 스크롤 없이 악보가 표시되고, 700px 이하의 보조 화면에서만 복잡한 악보에 가로 스크롤을 허용한다.
