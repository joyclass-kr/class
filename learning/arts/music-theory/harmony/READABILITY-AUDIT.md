# 화성학 가독성 점검

비교 기준은 같은 사이트의 piano-skills 보이싱 교재 화면이다. 보이싱 교재는 악보 패널을 본문 카드의 전폭으로 사용하고, SVG를 width: 100%로 표시한다. 화성학의 기존 좌우 2단 배치는 1024px·1180px 화면에서 악보 폭을 대략 480~560px로 줄여 음표, 임시표, 성부 이동을 작게 보이게 했다.

## 수정 원칙

- 설명 → 악보·시각자료 → 청음 순서로 한 방향으로 읽는다.
- 본문은 최대 72자 폭으로 제한해 긴 문장이 화면 끝까지 늘어나지 않게 한다.
- 악보는 최대 960px까지 확보하고 화면이 좁아지면 비율을 유지해 축소한다.
- 1024×768, 1180×820, 768×1024에서 모두 17px 본문과 44px 이상 조작 대상을 유지한다.
- 과정 목록은 현재 학습보다 앞에 나오지 않으며, 진도표 버튼으로 필요할 때 연다.

## 목표 화면별 예상 악보 폭

| 화면 | 수정 전 | 수정 후 |
| --- | ---: | ---: |
| 1024×768 | 약 500px | 약 900px |
| 1180×820 | 약 560px | 최대 960px |
| 768×1024 | 약 620px | 약 660px |

폭은 CSS 컨테이너와 패딩을 기준으로 계산했으며, 동일 규칙을 계약 테스트로 고정했다.
