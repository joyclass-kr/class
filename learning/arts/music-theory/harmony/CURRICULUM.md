# 화성학 진도

## 화면 구조

화성학 첫 화면은 설명용 메인 화면이 아니라 단계 선택 화면이다.

```text
← 메인
화성학

1. 음과 건반
2. 반음과 온음
3. 음정
4. 장음계와 조표
5. 단음계
6. 3화음
7. 코드의 전위
8. 다이어토닉 코드
9. 화음의 기능과 종지
10. 7화음과 기본 코드 진행
```

단계를 누르면 그 단계의 차시 목록을 보여 준다. 전체 차시를 첫 화면에 한꺼번에 펼치지 않는다.

## 1단계: 음과 건반

1. 높은음과 낮은음
2. 일곱 음이름
3. 흰건반에서 음 찾기
4. 옥타브

성취 목표: 음 이름을 보고 피아노 건반에서 해당 음을 찾는다.

## 2단계: 반음과 온음

1. 가장 가까운 두 음
2. 반음 두 개와 온음
3. 샵과 플랫
4. 이명동음

성취 목표: 두 음 사이의 반음 수를 건반에서 센다.

## 3단계: 음정

1. 음정의 도수
2. 완전음정
3. 장음정과 단음정
4. 증음정과 감음정
5. 음정 계산
6. 기본 음정 듣기

성취 목표: 두 음의 음정을 계산하고 기본 음정을 비교해 듣는다.

## 4단계: 장음계와 조표

1. 장음계의 온음·반음 배열
2. 장음계 만들기
3. 샵 조표
4. 플랫 조표
5. 오도권

성취 목표: 주어진 으뜸음으로 장음계를 만들고 조표를 읽는다.

## 5단계: 단음계

1. 관계조와 같은으뜸조
2. 자연단음계
3. 화성단음계
4. 가락단음계
5. 세 단음계 비교

성취 목표: 세 종류의 단음계를 구분하고 구성한다.

## 6단계: 3화음

1. 3도씩 음 쌓기
2. 장3화음
3. 단3화음
4. 감3화음
5. 증3화음
6. 네 종류의 3화음 듣기

성취 목표: 구성음과 소리로 네 종류의 3화음을 구별한다.

## 7단계: 코드의 전위

1. 기본위치
2. 제1전위
3. 제2전위
4. 베이스음 찾기
5. 전위형 듣기

성취 목표: 가장 낮은 음을 기준으로 3화음의 전위형을 판별한다.

## 8단계: 다이어토닉 코드

1. 장조의 다이어토닉 3화음
2. 로마숫자 표기
3. 단조의 다이어토닉 3화음
4. 조성이 바뀌어도 코드 찾기

성취 목표: 특정 조의 다이어토닉 코드를 구성하고 로마숫자로 표시한다.

## 9단계: 화음의 기능과 종지

1. 토닉
2. 서브도미넌트
3. 도미넌트
4. 정격종지와 반종지
5. 변격종지와 위장종지
6. 기능의 흐름 듣기

성취 목표: 화음의 기능과 기본 종지를 설명하고 구별한다.

## 10단계: 7화음과 기본 코드 진행

1. 장7화음
2. 도미넌트7화음
3. 단7화음
4. 반감7화음과 감7화음
5. I–IV–V–I
6. I–V–vi–IV
7. ii–V–I
8. 코드 진행 분석과 듣기

성취 목표: 기본 7화음과 자주 쓰는 코드 진행을 구성하고 듣는다.

## 단원 활동 유형

- 건반에서 음 찾기
- 두 음 사이의 거리 세기
- 음계 구성음 고르기
- 코드를 건반에 직접 쌓기
- 들은 음정 또는 코드 고르기
- 로마숫자와 실제 코드 연결하기
- 코드 진행의 기능 순서 맞추기

현재 피아노 재생 기능은 위 활동 전체에서 공통으로 사용한다.
