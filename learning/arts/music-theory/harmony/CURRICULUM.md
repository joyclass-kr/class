# 화성학 학습 순서

이 과정은 미리 정한 단원 수에 내용을 끼워 맞추지 않는다. 학생이 실제로 구별해서 수행해야 하고, 서로 다른 설명·악보·청음·오류 피드백이 필요한 개념만 별도 학습 항목으로 둔다.

## 범위

큰보표와 음정에서 시작해 3화음·7화음, 장단조의 기능, 4성부 연결, 비화성음, 종지와 연속진행, 변화화음과 전조를 거쳐 멜로디 화성화와 리드시트 완성까지 다룬다. 음향학·리듬 일반·악기 주법 전체는 별도 음악이론 과정의 범위로 둔다.

## 학습 묶음과 항목

| 묶음 | 학습 항목 |
|---|---|
| 악보와 음정 | 큰보표에서 음과 변화표 읽기 · 음정의 도수와 성질 계산하기 |
| 화음의 구성 | 3화음 구성 · 코드 기호 해독 · 3화음 성질 청음 · 전위와 슬래시 코드 · 7화음과 전위 |
| 조성과 기능 | 장조·단조의 조표와 음계 · 다이어토닉 코드 · 단조 기능화음 · 토닉·프리도미넌트·도미넌트 |
| 성부 연결 | 공통음과 최소 이동 · 4성부 음역·중복·진행 · 비화성음 · ii–V–I 가이드톤 |
| 종지와 진행 | 종지와 종지 6/4 · 연속진행 · 반복 진행 반주 · 화성 리듬 · sus·add·텐션 |
| 조성의 확장 | 조옮김 · 부속화음 · 차용화음 · 나폴리6·증6화음 · 공통화음 전조 |
| 화성화 | 멜로디 화성화 · 리드시트 분석·이조·편곡 |

## 한 항목의 완료 조건

각 항목은 다음 네 요소를 모두 가진다.

1. 원리와 대표 오개념을 설명하는 두 개 이상의 본문
2. 본문의 실제 음을 표시한 오선 악보
3. 비교 대상을 통제한 재생 가능한 피아노 청음
4. 직접 구성·청음·진행 만들기와 확인 문제

문제 개수와 설명 분량은 항목마다 같게 맞추지 않는다. 완료는 직접 활동과 확인 문제를 모두 마쳤을 때 기록한다.

## 순서 원칙

- 악보 철자와 음정을 먼저 익힌 뒤 화음을 쌓는다.
- 장조를 기준으로 다이어토닉 기능을 익힌 뒤 단조의 변화된 6·7음을 다룬다.
- 코드 이름을 외우는 것과 실제 성부를 연결하는 일을 분리한다.
- 비화성음과 화성 리듬을 이해한 뒤 멜로디에 코드를 붙인다.
- 부속화음과 종지로 새 중심이 확인될 때 전조로 판단한다.
- 조옮김과 전조를 서로 다른 학습 항목으로 다룬다.

## 화면 원칙

- 페이지를 열면 첫 학습 또는 마지막으로 보던 학습이 바로 열린다.
- 진도표는 보조 메뉴이며 광고형 첫 화면을 두지 않는다.
- 모든 항목은 열어 볼 수 있지만 선행 학습을 함께 표시한다.
- 1024×768, 1180×820, 768×1024에서 본문·악보·직접 활동이 순서대로 읽힌다.
- 버튼과 선택 요소는 최소 44×44 CSS 픽셀을 확보한다.
