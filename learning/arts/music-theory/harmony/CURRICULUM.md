# 화성학 학습 순서

이 과정은 미리 정한 단원 수에 내용을 끼워 맞추지 않는다. 학생이 실제로 구별해서 수행해야 하고, 서로 다른 설명·악보·청음·오류 피드백이 필요한 개념만 별도 학습 항목으로 둔다.

진도표의 각 항목은 고정 차시가 아니다. 한 항목은 필요한 설명·청음·작성·복습량에 따라 여러 차시에 걸쳐 사용할 수 있다.

## 범위

전문 화성가를 만드는 과정이 아니라 이후 음악 학습을 버틸 기초를 훈련한다. 기초악전과 음정을 충분히 익힌 뒤 3화음·전위, 장단조 기능, 기초 4성부, 비화성음, 종지, V7과 짧은 멜로디 화성화까지 다룬다.

세컨더리 도미넌트, 모달 인터체인지(차용화음), sus·add·기본 텐션은 기본 가요와 동요에도 쓰이므로 마지막 기초 확장으로 다룬다. 나폴리·증6화음, 본격 전조와 종합 리드시트 편곡은 필수 진도에 넣지 않는다.

나폴리6은 독립 필수 단원으로 만들지 않는다. 필요할 때 모달 인터체인지의 ♭II와 트라이톤 대리의 ♭II7을 비교하는 보충 사례로만 제시하고, 두 화음의 구성과 기능 차이를 분명히 적는다.

## 한 항목의 완료 조건

각 항목은 다음 네 요소를 모두 가진다.

1. 쉬운 말의 개념 설명과 중등 계산, 고등 적용으로 이어지는 본문
2. 세 단계 이상의 같이 풀기와 대표 오개념 피드백
3. 본문의 실제 음을 표시한 오선 악보
4. 비교 대상을 통제한 재생 가능한 피아노 청음
5. 직접 구성·청음·진행 만들기와 여러 확인 문제

문제 개수와 설명 분량은 항목마다 같게 맞추지 않는다. 완료는 직접 활동과 확인 문제를 모두 마쳤을 때 기록한다.

채점 문제는 조·음·성부·박 위치·적용 양식을 문장 안에 명시한다. 취향을 묻거나 여러 해석이 가능한 선택지는 사용하지 않고 정답 하나와 그 계산 근거를 제공한다.

## 순서 원칙

- 악보 철자와 음정을 먼저 익힌 뒤 화음을 쌓는다.
- 장조를 기준으로 다이어토닉 기능을 익힌 뒤 단조의 변화된 6·7음을 다룬다.
- 코드 이름을 외우는 것과 실제 성부를 연결하는 일을 분리한다.
- 4성부는 배치, 두 성부의 진행 유형, 오류 찾기를 서로 다른 학습 항목으로 반복한다.
- 제1전위 뒤에 종지·경과·보조·펼침 6/4를 별도 항목으로 다룬다.
- 비화성음과 화성 리듬을 이해한 뒤 멜로디에 코드를 붙인다.
- 조옮김은 같은 기능 관계를 다른 조에서 반복하는 기초 적용으로 다룬다.
- 전조와 변화화음은 기초 과정 이후의 별도 과정으로 남긴다.

## 화면 원칙

- 페이지를 열면 전체 진도표와 현재 추천 학습이 바로 보인다.
- 학습 목록 위에 제목·메뉴·광고형 첫 화면·반복 안내 문구를 두지 않는다.
- 학습 화면의 목록·다음 차시 이동 버튼은 본문 아래에 둔다.
- 모든 항목은 열어 볼 수 있지만 선행 학습을 함께 표시한다.
- 1024×768, 1180×820, 768×1024에서 본문·악보·직접 활동이 순서대로 읽힌다.
- 진도표의 각 학습 카드에는 해당 항목의 악보 미리보기가 있고, 수업에서는 첫 설명 다음에 큰 개념도와 오선 예시가 나온다.
- 버튼과 선택 요소는 최소 44×44 CSS 픽셀을 확보한다.
