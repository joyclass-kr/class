# 음악 이론 구조

음악 이론은 별도의 중간 페이지를 두지 않는다. 메인 `index.html`의 펼침 메뉴에서 화성학과 리듬으로 직접 이동한다.

```text
메인 인덱스
└─ 음악 이론
   ├─ 화성학 → learning/arts/music-theory/harmony/
   └─ 리듬   → learning/arts/music-theory/rhythm/
```

## 디렉터리 책임

- `harmony/`: 화성학 단계 목록, 개념 학습, 피아노 음원, 건반 활동, 청음 문제
- `rhythm/`: 리듬 단계 목록, 박자 학습, 메트로놈, 탭 활동, 리듬 받아쓰기

## 공통 설계 원칙

- 화성학과 리듬의 진도와 학습 기록은 서로 분리한다.
- 별도의 추천 또는 이어하기 화면을 만들지 않는다.
- 모든 단계는 선택 가능하게 두고 강제로 잠그지 않는다.
- 완료 여부는 단계 카드에만 간단히 표시한다.
- 각 단원은 `개념 → 직접 확인 → 연습 → 확인 문제` 순서로 진행한다.
- 현재 `music-studio`의 화면 구성은 재사용하지 않는다.
- 현재 피아노 음원과 검증된 피아노 재생 기능은 `harmony/`로 옮겨 재사용한다.
- 리듬 과정은 피아노를 불러오지 않고 메트로놈·카운트·리듬 타격음만 사용한다.
- 학생용 주요 조작은 44×44 CSS 픽셀 이상으로 만든다.
- 1024×768과 1180×820 가로 화면을 먼저 설계하고 768×1024 세로 화면을 함께 지원한다.

## 학습 기록

과정별로 단계 완료 상태만 저장한다. 이론 이해와 청음 성취를 하나의 잠금 조건으로 묶지 않는다.

```js
{
  version: 1,
  harmony: {
    completedLessons: [],
    lessonScores: {}
  },
  rhythm: {
    completedLessons: [],
    lessonScores: {}
  }
}
```

점수는 학생의 재도전을 막는 용도가 아니라 단계 카드에 학습 흔적을 보여 주는 용도로만 사용한다.
