# 리듬 진도

## 화면 구조

리듬 첫 화면도 단계 선택 화면으로 시작한다.

```text
← 메인
리듬

1. 박과 빠르기
2. 음표와 쉼표
3. 박자표
4. 8분음표
5. 점음표와 붙임줄
6. 16분음표
7. 당김음
8. 셋잇단음표와 복합박자
9. 리듬 읽기와 받아쓰기
```

## 1단계: 박과 빠르기

1. 일정한 박
2. 강박과 약박
3. 빠르기와 BPM
4. 박에 맞춰 탭하기

성취 목표: 일정한 박을 듣고 같은 간격으로 탭한다.

## 2단계: 음표와 쉼표

1. 4분음표와 4분쉼표
2. 2분음표와 2분쉼표
3. 온음표와 온쉼표
4. 음표 길이 비교

성취 목표: 기본 음표와 쉼표의 길이를 박 단위로 읽는다.

## 3단계: 박자표

1. 마디와 세로줄
2. 2/4박자
3. 3/4박자
4. 4/4박자
5. 강세로 박자 구별하기

성취 목표: 박자표를 읽고 마디의 박 수를 센다.

## 4단계: 8분음표

1. 한 박을 둘로 나누기
2. 8분음표 두 개
3. 4분음표와 8분음표 조합
4. 8분쉼표
5. 8분음표 리듬 따라 치기

성취 목표: 한 박의 2분할을 읽고 정확히 탭한다.

## 5단계: 점음표와 붙임줄

1. 점2분음표
2. 점4분음표
3. 같은 음을 잇는 붙임줄
4. 마디를 넘는 붙임줄

성취 목표: 점음표와 붙임줄로 늘어난 길이를 계산하고 연주한다.

## 6단계: 16분음표

1. 한 박을 넷으로 나누기
2. 네 개의 16분음표
3. 8분음표와 16분음표 조합
4. 16분쉼표
5. 16칸 비트 입력

성취 목표: 한 박의 4분할 패턴을 듣고 16칸에 표시한다.

## 7단계: 당김음

1. 여린박의 악센트
2. 오프비트
3. 박을 가로지르는 붙임줄
4. 기본 당김음 패턴

성취 목표: 강박을 벗어난 악센트와 당김음 패턴을 읽고 탭한다.

## 8단계: 셋잇단음표와 복합박자

1. 한 박의 3분할
2. 셋잇단음표
3. 6/8박자
4. 단순박자와 복합박자 비교
5. 3분할 리듬 듣기

성취 목표: 2분할과 3분할 리듬을 구별하고 6/8박자를 연주한다.

## 9단계: 리듬 읽기와 받아쓰기

1. 한 마디 초견 탭핑
2. 들은 악보 고르기
3. 한 마디 받아쓰기
4. 두 마디 기억하기
5. 혼합 리듬 종합 연습

성취 목표: 지금까지 배운 리듬을 악보와 소리 사이에서 변환한다.

## 단원 활동 유형

- 메트로놈에 맞춰 탭하기
- 음표 길이만큼 누르고 있기
- 박자표에 맞는 마디 고르기
- 들은 리듬과 같은 악보 고르기
- 8칸 또는 16칸에 리듬 표시하기
- 한 마디 리듬 받아쓰기

현재 `music-studio`의 16칸 비트 입력과 악보 선택 기능은 6단계와 9단계의 활동으로만 선별 이식한다.
