🗺️ 2D 리얼리티 (1:1 비율) 왜 행성이 안 보일까?
우주는 우리가 생각하는 것보다 훨씬 넓고 비어있습니다!

지구 반지름은 6,371km인데, 지구-태양 거리(1 AU)는 무려 1억 4,960만 km입니다. (거리 : 반지름 비약 23,500 : 1)

💡 만약 지구를 화면에서 1cm 크기로 그리면, 지구 궤도는 화면 밖 235m 멀리 나가버립니다!

따라서 실제 1:1 비율에서는 행성이 1픽셀보다 훨씬 작아져 눈에 안 보이기 때문에 선과 한글 라벨로 표기됩니다.
